# Teste — Site Som das 53 Assessoria

Pasta de **teste** desta conversa. Nada aqui é definitivo.

## Estrutura

```
teste-site-som-das-53/
├── materiais/
│   ├── imagens/    → logo, fotos, artes (PNG, JPG, SVG, WEBP)
│   ├── videos/     → vídeos (MP4, MOV)
│   └── arquivos/   → textos, PDFs, apresentações, tabelas
└── site/           → código do site (gerado pelo Claude)
```

## Como enviar os materiais pelo iPad (GitHub)

1. Abra o repositório no Safari: github.com/skellyns/skellyns
2. Troque o branch para `claude/53-assessoria-website-hxxsro`
3. Entre na pasta desejada (ex.: `teste-site-som-das-53/materiais/imagens`)
4. Toque em **Add file → Upload files**, escolha os arquivos no app Arquivos e confirme em **Commit changes**

Limite pelo navegador: 25 MB por arquivo. Vídeos maiores: use o Google Drive.
